# Ronda Histórica: visibility plan

Research checked on 9 October 2026. Site: https://rondahistorica.com. This is a report and a set of drafts. No emails, messages or posts have been sent.

Start with local history groups, two schools and local news. They have the clearest reason to share this project. Use a short screen recording to show what visitors can do. Ask people to explore a place they know and give useful corrections. After this first test, ask tourism partners to share the link.

The order below is a judgement about audience fit and effort. It is not a forecast of traffic. No audience size, response rate or promised coverage is assumed. “Verified” means a public contact route or rule was found; it does not mean that the recipient agreed to publish.

## 3. Prepare these small assets first

1. **A 25-second screen recording:** 0–4 seconds, Puente Nuevo today; 4–12 seconds, change the year from the same camera position; 12–20 seconds, explore the station or a familiar neighbourhood; 20–25 seconds, show the URL. Add readable Spanish captions. The clip should make sense without sound. Label reconstructed scenes clearly.
2. **Three still images:** the bridge, a city-wide comparison, and one neighbourhood. Caption model screenshots as “reconstrucción 3D”; do not present them as historical photographs. Keep required data and image credits with distributed material.
3. **A one-page classroom activity:** locate three landmarks; compare two periods; explain which details are documented and which are estimates. Test it with one teacher before asking a network to share it.
4. **A short project description and contact route:** identify Rubén as its creator and make it easy to report an incorrect date or location.
5. **A reliable first visit:** test the domain from mobile data and another network, then test the scene on a typical school laptop and a phone. Tell teachers how to mute the default background music before a classroom demo.

The local `index.html` inspected for this report has no description, canonical URL or Open Graph sharing tags. Add a clear title such as “Ronda Histórica — explora Ronda en 3D”, a short description, the main URL and a real screenshot for link previews. These are proposed changes, not changes made by this report. A short static introduction and clear source notes would also help explain the site before the 3D scene loads.

For search visibility, verify the domain in Search Console and inspect the live page. Request indexing when it is ready. Google explains that useful text, discoverable links and accessible resources help it understand a site; indexing and rankings are not guaranteed. [Google's guidance](https://developers.google.com/search/docs/fundamentals/seo-starter-guide)

| 6 | Submit a Three.js Showcase post with a screenshot, link and short technical explanation. | One moderated submission. |
| 7 | Review comments and access problems. Fix the most common issue; prepare the next clip around a specific place. | A short record of results and one improvement. |

Start with **€0 paid advertising**. Budget roughly 4–6 hours for preparation and personal contact; this is a planning estimate. A useful first test is whether one teacher, local-history group or editor actually tries the site and gives feedback. Do not judge the test only by likes.

Keep a simple record: channel, contact date, reply, agreed action, public link, and feedback. If analytics are added, measure successful scene loads and meaningful exploration as well as visits. Use separate campaign links only when the analytics system records them; URL tags alone do not produce a traffic report. No analytics implementation or visitor baseline was verified in this review.
